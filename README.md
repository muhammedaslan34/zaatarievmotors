
  # Futuristic EV Motors Website

This is a marketing website for ZAATARI EV Motors - Dubai. Built with Next.js and based on the Figma design available at https://www.figma.com/design/WLGPEJpiZZ9vPNDUKBV0oq/Futuristic-EV-Motors-Website.

## Tech Stack

- **Next.js 15** with App Router
- **React 18** with TypeScript
- **Tailwind CSS v4**
- **ShadCN UI** components
- **Framer Motion** for animations

## Running the code

```bash
npm i              # Install dependencies
npm run dev        # Start development server (http://localhost:3000)
npm run build      # Build for production
npm start          # Start production server
```

## Project Structure

- `app/` - Next.js App Router pages and layout
- `src/pages/` - Page components
- `src/components/` - Reusable components
- `src/assets/` - Static images and assets
